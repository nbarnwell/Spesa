# Architecture Decision Records

This directory records significant architectural decisions for Spesa — the kind that would be awkward or expensive to reverse (data model, service boundaries, key libraries).

Each record is a numbered Markdown file (`NNNN-title.md`) with four sections: **Status**, **Context**, **Decision**, **Consequences**. A record is never edited to reflect a later reversal — a superseding decision gets its own new record that links back to the one it replaces.
